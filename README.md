# روليت الإثارة

لعبة عربية خاصة للزوجين، تعمل من جوالين عبر غرفة ورابط دعوة. يختار كل لاعب اسمه وجنسه، وتظهر البطاقة على الجهازين بصياغة صاحب الدور مع مزامنة الدور والمرحلة والبطاقات المتبقية.

بعد كل بطاقتين مكتملتين تبدأ «جولة همسة سرية»: يظهر سؤال مختلف لكل طرف، ويكتب كل واحد إجابته على جهازه. لا تصل إجابة الطرف الآخر في استجابة حالة الغرفة إلا بعد اكتمال الإجابتين وانتهاء عدّ تنازلي مدته أربع ثوانٍ. يرتفع مؤشر اللهيب مع إتمام البطاقات وإرسال الإجابات، بينما يخفضه التخطي ويصفّر سلسلة الحماس.

## التشغيل

```bash
npm install
npm run db:push        # قاعدة جديدة
npm run db:migrate     # ترقية قاعدة قائمة دون حذف بياناتها
npm run dev
```

يعمل الخادم والواجهة على المنفذ `3000`. يلزم ضبط `DATABASE_URL` في ملف `.env` قبل مزامنة قاعدة البيانات.

## البناء والفحص

```bash
npm run check
npm run build
npm start
```

## فحص النشر

بعد تشغيل الخادم، يعرض `GET /api/health` حالة الخادم وقاعدة البيانات دون كشف بيانات الغرف أو اللاعبين. الاستجابة السليمة تكون `200` مع `ok: true` و`database: connected`، وأي تعذر للاتصال بقاعدة البيانات يعيد `503`.

## البنية

- `contracts/cards.ts`: بطاقات المراحل الأربع بصياغتي المذكر والمؤنث.
- `contracts/secret.ts`: أسئلة الجولات السرية المتدرجة.
- `api/roomRouter.ts`: الغرف والأدوار والبطاقات والإجابات السرية والكشف واللهيب.
- `db/schema.ts`: جداول الغرف واللاعبين وحالة الجولة السرية.
- `src/pages/Home.tsx`: شاشة الدخول والدعوة واللعب ومؤشر التقدم.
- `src/game/SecretRound.tsx`: الكتابة والانتظار والعدّ التنازلي والكشف.
- `src/game/Dial.tsx`: قرص البطاقات.

رموز جلسات اللاعبين تُحفظ كبصمات مشفرة في قاعدة البيانات، ولا يتضمن رابط الدعوة رمز جلسة أي لاعب. روابط الدعوة الجديدة تستخدم `?join=CODE`، وتظل الروابط القديمة بصيغة `?room=CODE` مدعومة.
