# روليت الإثارة

لعبة عربية خاصة للزوجين، تعمل من جوالين عبر غرفة ورابط دعوة. يختار كل لاعب اسمه وجنسه، وتصله البطاقة نفسها بصياغة مذكرة أو مؤنثة مع مزامنة الدور والمرحلة والبطاقات المتبقية.

## التشغيل

```bash
npm install
npm run db:push
npm run dev
```

يعمل الخادم والواجهة على المنفذ `3000`. يلزم ضبط `DATABASE_URL` في ملف `.env` قبل مزامنة قاعدة البيانات.

## البناء والفحص

```bash
npm run check
npm run build
npm start
```

## البنية

- `contracts/cards.ts`: بطاقات المراحل الأربع بصياغتي المذكر والمؤنث.
- `api/roomRouter.ts`: إنشاء الغرف، الانضمام، اختيار البطاقات، وتبديل الأدوار.
- `db/schema.ts`: جداول الغرف واللاعبين.
- `src/pages/Home.tsx`: شاشة الدخول والدعوة واللعب.
- `src/game/Dial.tsx`: قرص البطاقات.

رموز جلسات اللاعبين تُحفظ كبصمات مشفرة في قاعدة البيانات، ولا يتضمن رابط الدعوة رمز جلسة أي لاعب.
