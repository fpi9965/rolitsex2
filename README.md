# روليت الإثارة

لعبة عربية خاصة للزوجين، تعمل من جوالين عبر غرفة ورابط دعوة. يختار كل لاعب اسمه وجنسه، ويختار كل سحب مصدرين مستقلين للبطاقات بحيث يظهر سؤال أو تكليف مختلف فعلياً على كل جهاز، مع مزامنة الدور والمرحلة والبطاقات المتبقية.

بعد كل بطاقتين مكتملتين تبدأ «همسة سرية»: سؤال مختلف لكل طرف وإجابة مكتوبة على كل جهاز. لا تتضمن استجابة حالة الغرفة سؤال الطرف الآخر أو إجابته قبل اكتمال الإجابتين وانتهاء عدّ تنازلي مدته أربع ثوانٍ. تُضبط الساعة على وقت الخادم، وتحفظ مسودة الإجابة محلياً على الجهاز حتى تُرسل.

يرتفع مؤشر اللهيب مع إتمام البطاقات وإرسال الإجابات، بينما يخفضه التخطي ويصفّر سلسلة الحماس. تبدأ مع كل بطاقة 90 ثانية للتحدي، ويتزامن العدّ بين الجهازين اعتماداً على وقت الخادم ويستمر بعد إعادة تحميل الصفحة. عند انتهاء الوقت تبقى البطاقة متاحة للإتمام أو التخطي دون عقوبة. عند استهلاك مرحلة والعودة إليها لاحقاً، تتجدد مجموعتها مع تجنب التكرار قدر الإمكان. تتضمن كل مجموعة سحب جديدة نسبة من الإضافات الحديثة حتى تظهر فعلياً أثناء اللعب.

## التشغيل

```bash
npm install
npm run db:push        # قاعدة جديدة
npm run db:migrate     # ترقية قاعدة قائمة دون حذف بياناتها
npm run dev
```

يعمل الخادم والواجهة على المنفذ `3000`. يلزم ضبط `DATABASE_URL` في ملف `.env` قبل مزامنة قاعدة البيانات.

## البناء والفحص

```bash
npm run check
npm run test
npm run build
npm start
```

تختبر المكتبة أعداد البطاقات واكتمال الصياغتين واختلاف مصدر ونص بطاقة كل جهاز في جميع المراحل، وقاعدة أن مداعبة المؤخرة أو الشرج يقوم بها الزوج للزوجة فقط. يعرض `GET /api/health` حالة الخادم وقاعدة البيانات دون كشف بيانات الغرف أو اللاعبين.

## البنية

- `contracts/cards.ts`: 184 زوجاً من البطاقات في أربع مراحل، منها 32 إضافة ثنائية مختلفة النص للجهازين.
- `contracts/secret.ts`: أسئلة الجولات السرية المتدرجة.
- `contracts/game.ts`: العقود المشتركة وقواعد النقاط والمراحل.
- `api/roomRouter.ts`: الغرف والأدوار والبطاقات والإجابات والكشف واللهيب.
- `api/cardPairing.ts`: اختيار مصدر مستقل لبطاقة الطرف الآخر ومنع تطابق النصين.
- `db/schema.ts`: جداول الغرف واللاعبين وحالة الجولة السرية.
- `src/pages/Home.tsx`: إدارة الجلسة والاتصال والعمليات.
- `src/game/EntryScreen.tsx`: إنشاء الغرفة والتحقق من الدعوة والانضمام.
- `src/game/InvitePanel.tsx`: نسخ الدعوة ومشاركتها.
- `src/game/GameScreen.tsx`: شاشة اللعب والمراحل والأدوار.
- `src/game/SecretRound.tsx`: المسودة والكتابة والانتظار والعدّ والكشف.
- `src/game/Dial.tsx`: قرص البطاقات.
- `src/game/session.ts`: استعادة الجلسة والخروج والروابط والمسودات.

العمليات لا تعتمد على رقم نسخة قد يكون قديماً بسبب تأخر الشبكة؛ تتحقق الخادم من الدور والحالة داخل معاملة وقفل للغرفة. رموز جلسات اللاعبين تُحفظ كبصمات SHA-256 في قاعدة البيانات، ولا يتضمن رابط الدعوة رمز جلسة أي لاعب. روابط الدعوة تستخدم `?join=CODE`، وتظل الروابط القديمة بصيغة `?room=CODE` مدعومة.

عند إنشاء الدعوة داخل معاينة `kimi.ai` الخاصة، يتحول الرابط تلقائياً إلى النشر العام بدلاً من إرسال رابط معاينة لا يستطيع الجهاز الآخر فتحه. يمكن تغيير الدومين العام عبر `VITE_PUBLIC_URL` دون تعديل الكود. النشر العام نفسه يتم يدوياً من زر «نشر».
