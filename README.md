# روليت الإثارة

لعبة عربية خاصة للزوجين، تعمل من جوالين عبر غرفة ورابط دعوة. يختار كل لاعب اسمه وجنسه، وتظهر البطاقة على الجهازين بالصياغة الموجهة إلى صاحب الدور، مع مزامنة الدور والمرحلة والبطاقات المتبقية.

بعد كل بطاقتين مكتملتين تبدأ «همسة سرية»: سؤال مختلف لكل طرف وإجابة مكتوبة على كل جهاز. لا تتضمن استجابة حالة الغرفة سؤال الطرف الآخر أو إجابته قبل اكتمال الإجابتين وانتهاء عدّ تنازلي مدته أربع ثوانٍ. تُضبط الساعة على وقت الخادم، وتحفظ مسودة الإجابة محلياً على الجهاز حتى تُرسل.

يرتفع مؤشر اللهيب مع إتمام البطاقات وإرسال الإجابات، بينما يخفضه التخطي ويصفّر سلسلة الحماس. عند استهلاك مرحلة والعودة إليها لاحقاً، تتجدد مجموعتها مع تجنب التكرار قدر الإمكان.

## التشغيل

```bash
npm install
npm run db:push        # قاعدة جديدة
npm run db:migrate     # ترقية قاعدة قائمة دون حذف بياناتها
npm run dev
```

يعمل الخادم والواجهة على المنفذ `3000`. يلزم ضبط `DATABASE_URL` في ملف `.env` قبل مزامنة قاعدة البيانات.

## البناء والفحص

```bash
npm run check
npm run test
npm run build
npm start
```

تختبر المكتبة أعداد البطاقات واكتمال الصياغتين وقاعدة أن مداعبة المؤخرة أو الشرج يقوم بها الزوج للزوجة فقط. يعرض `GET /api/health` حالة الخادم وقاعدة البيانات دون كشف بيانات الغرف أو اللاعبين.

## البنية

- `contracts/cards.ts`: 152 زوجاً من البطاقات في أربع مراحل.
- `contracts/secret.ts`: أسئلة الجولات السرية المتدرجة.
- `contracts/game.ts`: العقود المشتركة وقواعد النقاط والمراحل.
- `api/roomRouter.ts`: الغرف والأدوار والبطاقات والإجابات والكشف واللهيب.
- `db/schema.ts`: جداول الغرف واللاعبين وحالة الجولة السرية.
- `src/pages/Home.tsx`: إدارة الجلسة والاتصال والعمليات.
- `src/game/EntryScreen.tsx`: إنشاء الغرفة والتحقق من الدعوة والانضمام.
- `src/game/InvitePanel.tsx`: نسخ الدعوة ومشاركتها.
- `src/game/GameScreen.tsx`: شاشة اللعب والمراحل والأدوار.
- `src/game/SecretRound.tsx`: المسودة والكتابة والانتظار والعدّ والكشف.
- `src/game/Dial.tsx`: قرص البطاقات.
- `src/game/session.ts`: استعادة الجلسة والخروج والروابط والمسودات.

العمليات لا تعتمد على رقم نسخة قد يكون قديماً بسبب تأخر الشبكة؛ تتحقق الخادم من الدور والحالة داخل معاملة وقفل للغرفة. رموز جلسات اللاعبين تُحفظ كبصمات SHA-256 في قاعدة البيانات، ولا يتضمن رابط الدعوة رمز جلسة أي لاعب. روابط الدعوة تستخدم `?join=CODE`، وتظل الروابط القديمة بصيغة `?room=CODE` مدعومة.
